AutoArm 4.0.4 — Socket controls and docking stability

Bare-arm manual facing and HEAD controls now use the exposed rotor socket as
forward. Q/E and Roll steps rotate around its shaft. Native observation and
ToolSwap coupling frames are unchanged.

Automatic pose correction now has a precision band equal to half the active
position/angular tolerance, preserving retained load compensation. Linear
lookahead includes that band so even minimum-speed paths continue moving.
Forward insertion demand blends continuously as alignment worsens rather than
switching abruptly on/off at the tolerance boundary. Full endpoint distance,
measured settling and attachment proofs still govern completion.

Parking defaults are 0.01 metres and 1 degree. Rotor pickup retains 0.003 metres
and 0.2 degrees. Existing Custom Data overrides remain in force: change
Tools.PositionTolerance=0.01 and Tools.AngleTolerance=1 in the ToolSwap PB's
[global] or target arm section if it still contains the older tighter values.

Parking enables support, observes locked support and the correct source mount
on consecutive timed observations, then detaches. A temporarily missing source
attachment after proven merge support waits stopped for at most two seconds.
Permanent loss, wrong top/owner or lost support cancels. Pickup confirms the
correct attachment before disabling support merges.

Detached mount phase checks now apply only to the relevant non-axial incoming
cached target and compare wrapped angles. Source/inactive mounts and expected
attachment transitions no longer trigger the broad mount-angle error.

History audit found a retained-integral/damping conflict at input release.
New damping defaults return to zero; explicit user values remain unchanged.
Manual PI gains remain unchanged. The user's zero-damping trial did not improve
severe shaking; lowering PositionCorrectionCap to 0.05 reduced manual shaking
but did not help parking. Automatic motion has its own caps. The docking repairs
above still require live in-game confirmation on that arm.

Update BOTH PBs, retaining current formats (Arm 7, ToolSwap 2) and protocol 5.
Run On; it reloads configuration and scans equipment automatically.
