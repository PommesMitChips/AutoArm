AutoArm 4.0.5 — Tool connection settling and confirmed handoff

Fixes false 'Attachment lost' after pickup and 'Source detached prematurely'
during parking. The declared merge/unmerge windows allow temporarily missing
attachment observations while output is stopped, bounded to two seconds and
restricted to the known tool/top/owner. Initial parking support flags may settle
before proof; lost proven support, wrong parts and foreign owners still abort.

Lock, Detach, Attach and Release require continuously valid connection/support
or split observations for 0.2 seconds. Timing starts at the first true sample;
a delayed first tick cannot count unseen time. The arm rebuilds only after the
connection has settled, then resumes automatically.

ToolSwap now waits for acknowledgement of the current handoff and actual arm
ON before reporting success. Requests are retried while the movement lease is
still held, with a bounded retry count. Duplicate accepted RESUME requests only
acknowledge current state; they do not stop, recapture or restart the arm.
Prior protocol errors are cleared at valid new acceptance, and current resume
readiness/permission/budget/validation failures are reported rather than left
pending indefinitely. An explicit Off before confirmation remains Off and
reports its reason. Resume waiting is included in communication supervision.

Update BOTH PB scripts, keep existing Custom Data, then run On on the Arm PB.
No configuration changes are required. Arm Format 7, ToolSwap Format 2 and
protocol 5 remain unchanged. Manual movement, solver and PID code are unchanged
from 4.0.4; the experimental manual learner remains rejected and test-only.

Validation: installed SE API / C#6, specialization, packing token/compile and
identical-method-IL gates, plus 195,696 simulated assertions. Tests cover initial
staggered merge flags, post-unmerge pointer gaps, false-sample timer reset,
contradictory/permanent loss, lost request/confirmation, preserved active target
on retry, old errors, explicit Off and bounded resume failures. Actual multi-arm
hosts inject connection gaps and retain independent neighboring-arm control.
Live SE physics and instruction costs remain unverified.

Arm: 99,449 characters, 551 free. ToolSwap: 65,142, 34,858 free.
