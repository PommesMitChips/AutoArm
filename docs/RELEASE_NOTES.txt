CONFIGURATION
Custom Data requires Format=4. Wrong, missing or invalid formats are rejected;
save settings you wish to retain, delete Custom Data and run Reload.
No config migration is included. Saved Home still needs a matching fingerprint.

TOOL LAYOUT
The compatible unnamed rotor/hinge TOP stays on the arm.
Each tool carries a named rotor/hinge BASE, marker and optional head merges.
[Tools] Mount names a fixed terminal reference on the arm-tip grid.
[ToolNN] Mount names the base on that tool. Heads lists exact markers.
Start a fresh installation with any compatible tool attached. Its real Top
establishes the single arm-tip identity/geometry automatically. Every other
named parked tool can then be selected immediately; no per-tool teaching or
manual setup mount is required. The arm-tip record persists across a headless
restart of the same PB. A new PB or changed arm tip/reference needs setup
with one attached tool.

Parking verifies all selected merges before the source TOOL BASE detaches.
Pickup computes the arm-reference goal from the incoming visible BASE pose,
retained angle, subtype and displacement, then requests Attach on that base.
Exact arm-top identity, reciprocal owner, grid and two aligned observations
are required before disabling only the selected tool's head merges. Actual
split precedes topology rebuilding. Interrupted swaps stay OFF and preserve
support; explicit ToolScan reconciles recovery. Failed pending requests are
cancelled only when a base is observed bare, then bare state must persist.
Unsupported/corrupt layouts and unexpected ownership refuse motion.

MOVEMENT REUSE
MoveTo x y z sets absolute Base Forward/Left/Up position in metres.
OrientTo fx fy fz ux uy uz sets normalized forward/up directions in that frame.
MoveToPosOri accepts both (nine values). On is required; normal live pilot
input remains additive. Invalid arity, non-finite and degenerate directions
are rejected before any target assignment. The common target setter is also
used by Face, Step and tool pose motion; tool-only guards/caps are retained.
Enable and Hold share observation/bias reset. GoHome keeps native joint-space
routes, limits and exact saved configuration instead of Cartesian IK.
