# SVG panels

AutoArm and ToolSwap guide panels and command references.

| Folder | Contents |
| --- | --- |
| `autoarm-guide/` | Getting Started with AutoArm |
| `toolswap-guide/` | ToolSwap setup |
| `commands/` | AutoArm and ToolSwap commands |
| `common/` | A separator to place between panels |
| `fonts/` | Inter and Oxanium fonts |

Open an SVG in Inkscape, Illustrator or another vector editor to change the text,
colours or illustrations. Install the included fonts if the text looks different.
The panels use light text, so view them against a dark background.

Open [preview.html](preview.html) to browse the panels. Use the
[panel assembler](../../../../tools/panel-assembler/README.md) to arrange them
and export PNGs or a combined SVG.
