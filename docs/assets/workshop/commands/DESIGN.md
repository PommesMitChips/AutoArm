# Command reference panels

Preserve the guide's Inter/Oxanium typography, light steel text, amber emphasis,
thin separators and fully transparent canvas. The use context is a reader
scanning a Workshop image for a command and its arguments.

- **THESIS:** Find the right Run argument, its PB, argument units and target arm.
- **OWN-WORLD:** The approved guide's typography and palette, with monospace only
  for command syntax and examples where character structure matters.
- **STORY:** Command syntax, AutoArm groups, then ToolSwap operations and control.
- **FIRST VIEWPORT:** How to enter and target a command, with batch behavior.
- **FORM:** One readable column at 620px logical width, exported at 2x to PNG.
  Each image identifies its PB and category, and each row gives syntax, meaning,
  aliases and necessary examples. No section numbers imply a required sequence.

Listed verbs are checked against source, with explicit user-requested omissions.
The control wrapper and its short alias are excluded from the panels. Numeric aiming shortcuts, legacy
aliases, PivotProbe, local pose frames and world-space Path are explicit. ToolSwap
selection does not claim cockpit pairing, and unsupported AutoArm commands are
not presented as ToolSwap commands. Source evidence is in the catalog and manifest.
